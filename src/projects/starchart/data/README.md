# Sky data

Generated by `scripts/build-sky-data.mjs`. Do not edit the `*.gen.ts` files.

Reduced from [ofrohn/d3-celestial](https://github.com/ofrohn/d3-celestial) `data/`,
which is BSD-3-Clause. That data derives from the Hipparcos and Tycho catalogues,
the IAU constellation figures, and the Milky Way outlines traced for that project.

| file | contents |
| --- | --- |
| `stars.gen.ts` | 41411 stars to mag 8, 6 bytes each |
| `starNames.gen.ts` | 4807 designations |
| `constellations.gen.ts` | 89 figures |
| `milkyway.gen.ts` | 512x256 brightness map |

Positions are J2000 equatorial, RA 0..360 degrees. Proper motion is not applied:
over the centuries the plate furniture implies it is well under a pixel.
